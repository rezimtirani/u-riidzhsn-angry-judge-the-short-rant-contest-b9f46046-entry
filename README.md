One short rant about an everyday annoyance: the office printer, which only ever jams on the one document that matters.

> The printer has never once jammed on a document nobody needed. It waits, patient and fully inked, until the one page that decides your morning, then eats it, blinks orange, and prints a perfect test page nobody asked for — as if to say: I could do it. I just chose not to.

## How it works

`main.py` (Python 3 standard library only) writes the rant to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: 1 to 400 characters of UTF-8 text.

```sh
python3 main.py
```
